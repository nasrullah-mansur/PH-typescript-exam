## অ্যাসাইনমেন্ট পরিচিতি

এই অ্যাসাইনমেন্টে `TypeScript` এর জ্ঞান ব্যবহার করে মোট ৮ টি প্রবলেম সলভ করা হয়েছে। এখানে ব্যবহার করা হয়েছে `TypeScript` এর `Basic Types, Union Types, Generics, Interfaces, Readonly, Tuples, Rest Parameters, Promises` এবং `Object-Oriented Programming (OOP)` এবং কোডগুলো যথাসম্ভব গুছিয়ে ও সংক্ষিপ্ত আকারে লেখার চেষ্টা করা হয়েছে।

## দুটি ব্লগ লেখা

অ্যাসাইনমেন্টের অংশ হিসেবে দুটি গুরুত্বপূর্ণ বিষয় নিয়ে বাংলায় ‍দুটি আলাদা ব্লগ লেখা হয়েছে।

### ১. Type vs Interface in TypeScript

এই ব্লগে TypeScript-এর `type` এবং `interface` এর পার্থক্য, এবং কোন পরিস্থিতিতে কোনটি ব্যবহার করা উচিত, তা উদাহরণসহ আলোচনা করা হয়েছে।

**[ব্লগটি পড়ুন: Type vs Interface](./type-vs-interface.md)**

### ২. Access Modifiers in TypeScript OOP

এই ব্লগে `public`, `private`, `protected` এবং `readonly` modifiers সম্পর্কে সুন্দরভাবে আলোচনা করা হয়েছে।

**[ব্লগটি পড়ুন: TypeScript Access Modifiers](./typescript-access-modifiers.md)**
